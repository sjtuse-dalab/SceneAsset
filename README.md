# SceneAsset

Large scene assets used by WanPhys examples.

## City flood

`city/new_largecity.zip` contains:

- `LowPoly_City_01Ready.obj`
- `newLowPoly_City_01Ready.mtl`
- `textures/palette.jpg`

The WanPhys city-flood example downloads this archive through Newton's Git
asset cache and extracts it locally on first use. The archive remains outside
the WanPhys source repository.
